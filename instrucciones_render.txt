==== INSTRUCCIONES PARA DESPLEGAR EN RENDER ====

1. CREAR BASE DE DATOS POSTGRESQL EN RENDER
=============================================
1. Inicia sesión en tu cuenta de Render.
2. Ve a la sección "New +" y selecciona "PostgreSQL".
3. Configura la base de datos:
   - Nombre: confessiones-db (o el nombre que prefieras)
   - Usuario: Deja el valor predeterminado
   - Región: Selecciona la más cercana a tus usuarios
   - Plan: Selecciona el plan que mejor se adapte a tus necesidades
4. Haz clic en "Create Database".

2. CREAR WEB SERVICE PARA LA APLICACIÓN
========================================
1. Ve a la sección "New +" y selecciona "Web Service".
2. Conecta tu repositorio de GitHub o sube tu código fuente.
3. Configura el servicio:
   - Nombre: confessiones (o el nombre que prefieras)
   - Entorno: Python
   - Región: La misma que seleccionaste para la base de datos
   - Branch: main (o la rama principal de tu repositorio)
   - Comando de Construcción (Build Command): pip install -r render_requirements.txt && chmod +x ./install_postgresql.sh && ./install_postgresql.sh
   - Comando de Inicio (Start Command): gunicorn main:app
   - Plan: Selecciona el plan que mejor se adapte a tus necesidades

4. FINALIZAR DESPLIEGUE
=======================

===========================================
El panel de administrador te permite:

========================
